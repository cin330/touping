## 1. 需要配置的环境

分两种情况：**只是使用**，配好 1.1 和 1.2 就够；**要从源码运行或自己打包**，再配 1.4。

### 1.1 电脑（必须）

| 项目 | 要求 |
| --- | --- |
| 系统 | Windows 10 或 11，64 位 |
| 磁盘 | 约 120 MB |
| 数据线 | 能传数据的 USB 线，只能充电的线不行 |
| 权限 | 普通用户即可，不需要管理员 |
| USB 驱动 | 多数设备不用装。插上后一直检测不到，再去装平板品牌的官方 USB 驱动 |

**不需要**安装 Python、adb、scrcpy，也**不需要**配置 PATH 等环境变量。程序只用自带的 scrcpy 5.0.1 和 adb。

建议关掉手机助手、刷机工具、安卓模拟器：它们自带的 adb 会和本程序抢连接（都用 5037 端口）。

### 1.2 平板或手机（必须，只配一次）

| 项目 | 要求 |
| --- | --- |
| 系统 | 安卓 5.0 以上 |
| 声音传到电脑 | 安卓 11 以上；安卓 11 还要保持屏幕解锁，12 以上直接可用 |
| USB 调试 | 打开 |

打开 USB 调试：

1. 打开开发者选项：连续点 7 次下表里的项目。

   | 品牌 | 位置 |
   | --- | --- |
   | 多数设备 | 设置 → 关于平板电脑 → 版本号 |
   | 三星 | 设置 → 关于平板电脑 → 软件信息 → 编译编号 |
   | 小米、红米 | 设置 → 关于平板 → MIUI 版本或 OS 版本 |

2. 设置里找到“开发者选项”（常在最底部，或在“系统”“更多设置”里），打开“USB 调试”。
3. 部分品牌还有额外开关：
   - **小米、红米**：再打开“USB 调试（安全设置）”，否则只能看画面，电脑键鼠不起作用。
   - **三星**：如果“USB 调试”是灰色的，先到 设置 → 安全和隐私 里关掉“自动拦截”（Auto Blocker）。

各系统版本的菜单名会略有不同，找不到时在设置里搜索“版本号”“编译编号”或“USB 调试”。

### 1.3 无线投屏（可选）

- 电脑和平板连同一个 Wi‑Fi。
- 第一次要先插着线，见 [6. 无线投屏](#6-无线投屏)。

### 1.4 从源码运行或打包（可选）

| 工具 | 版本 | 说明 |
| --- | --- | --- |
| uv | 较新版本即可（本项目用 0.12 验证） | 管理 Python 和依赖 |
| Python | 3.11 以上，推荐 3.13 | 不用单独装，电脑上没有时 uv 会自动下载 |
| PySide6-Essentials | 6.12.0 | `uv sync` 自动装 |
| pywin32 | 312 | `uv sync` 自动装 |
| pytest、PyInstaller | 9.2.0、6.22.3 | 测试和打包用，`uv sync` 自动装 |
| 网络 | 能访问 PyPI 和 GitHub | 下载依赖和 scrcpy |

在 PowerShell 里，进入项目文件夹后依次运行：

```powershell
winget install --id astral-sh.uv -e                                 # 装 uv，装完重开 PowerShell
uv sync --python 3.13                                               # 建 .venv，装依赖
powershell -ExecutionPolicy Bypass -File scripts\fetch_scrcpy.ps1   # 下载 scrcpy 5.0.1 并校验
```

环境变量都是可选的，平时不用设：

| 变量 | 作用 | 不设时 |
| --- | --- | --- |
| `TOUPING_HOME` | 配置和日志放在哪个文件夹 | `%APPDATA%\TouPing` |
| `ANDROID_ADB_SERVER_PORT` | adb 的端口 | 5037 |

### 1.5 检查环境配好没有

先插上平板，再在 PowerShell 里运行（源码版把 `scrcpy\` 换成 `vendor\scrcpy\`）：

```powershell
scrcpy\scrcpy.exe --version     # 应显示 scrcpy 5.0.1
scrcpy\adb.exe devices          # 看平板的状态
```

| `adb devices` 显示 | 意思 | 怎么办 |
| --- | --- | --- |
| 序列号 + `device` | 配好了 | 可以投屏 |
| 序列号 + `unauthorized` | 还没授权 | 解锁平板，在弹窗里勾选“一律允许”再点允许 |
| 序列号 + `offline` | 连接异常 | 重新插线，或换一个 USB 口 |
| 什么都没有 | 没检测到 | 换数据线，确认 USB 调试已打开，再考虑装驱动 |

## 2. 安装和启动

**打包版**：把整个 `TouPing` 文件夹放到任意位置，双击 `TouPing.exe`。不要只拷 exe，旁边的文件都要带上。

**源码版**：双击 `run.pyw`，或运行：

```powershell
.venv\Scripts\python.exe -m touping
```

程序没有主窗口，启动后在任务栏右下角的托盘里（可能收在 `^` 里面）：

| 图标 | 状态 |
| --- | --- |
| 灰色 | 没有设备 |
| 黄色 | 设备未授权，或正在连接 |
| 空心绿 | 设备已连接，没在投屏 |
| 实心绿 | 正在投屏 |

左键单击图标开始或停止投屏，右键打开菜单。想开机就运行：右键 → 设置… → 勾选“开机自动启动”。

**改了源码后重新打包**：先右键托盘图标 → 退出，再运行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build.ps1
```

产物在 `dist\TouPing`。如果提示文件被占用，先运行 `dist\TouPing\scrcpy\adb.exe kill-server` 再打包。
设置存在 `%APPDATA%\TouPing`，重新打包或换新版本不会丢。

## 3. 第一次投屏

1. 启动程序，托盘图标是灰色。
2. 用数据线连接平板。
3. 平板弹出“允许 USB 调试吗？”，勾选“一律允许”，点允许。
4. 几秒内出现投屏窗口，图标变成实心绿。

之后每次插线都会自动投屏，拔线自动关闭。窗口的位置和大小会记住。

## 4. 快捷键

快捷键是全局的：不管正在用哪个程序，按下就有效。

### 4.1 默认快捷键

| 快捷键 | 功能 | 正在投屏时 | 没在投屏时 |
| --- | --- | --- | --- |
| `Alt+1` | 展示投屏 | 从最小化还原，并放到最前面 | 开始投屏；没插设备则提示 |
| `Alt+2` | 最小化投屏 | 收到任务栏，投屏不断开 | 提示“当前没有投屏” |
| `Alt+3` | 关闭投屏 | 关掉投屏窗口，停止投屏 | 提示“当前没有投屏” |
| `Ctrl+Alt+M` | 开始/停止投屏 | 停止 | 开始 |
| `Ctrl+Alt+P` | 切换预设 | 换预设并重新投屏 | 换预设，下次投屏生效 |

- **`Alt+2` 和 `Alt+3` 的区别**：最小化后连接还在，`Alt+1` 立刻回来；关闭后要重新连接，`Alt+1` 会慢一点。
- **`Alt+3` 之后不会自己弹出来**：要再看，按 `Alt+1`，或重新插线。
- **`Alt+3` 关的是电脑上的投屏窗口**，平板的屏幕不受影响，程序也还在托盘里。
- 数字指键盘上方那一排，小键盘的数字不算。
- 推荐用**左 Alt**。右 Alt 也能触发，但在投屏窗口里会同时传给平板。

一个常用的流程：插线自动投屏 → `Alt+2` 收起来写东西 → `Alt+1` 调出来看 → 用完 `Alt+3` 关掉。

### 4.2 修改快捷键

1. 右键托盘图标 → 设置…。
2. 在“全局快捷键”里点一下要改的输入框。
3. 直接按新的组合键，比如按 `Ctrl+Alt+1`，输入框会显示出来。
4. 点“保存”，立即生效，不用重启。

| 想做什么 | 怎么做 |
| --- | --- |
| 不用某个快捷键 | 点输入框右边的 ×，再保存 |
| 互换两个快捷键 | 分别改好，一起保存 |
| 全部改回默认 | 点“恢复默认快捷键”，再保存 |
| 反悔 | 点“取消” |

规则：

- 必须带 `Ctrl`、`Alt` 或 `Win`，可以再加 `Shift`。只有 `Shift` 不行，否则会挡住打字。
- 主键可以是字母、数字、F1–F24、方向键、空格、Home、End、PageUp、PageDown、Insert、Delete。标点符号不行。
- 五个快捷键不能重复，重复时会提示是哪两个。
- **设置窗口开着时，所有快捷键都暂停**，关掉窗口就恢复。

### 4.3 和其他程序冲突

本程序运行时，`Alt+1`、`Alt+2`、`Alt+3` 会优先归它，其他程序收不到。比如：

- VS Code 的 `Alt+1` 等切换标签页；
- Word、Excel 的 `Alt+1` 等快速访问工具栏。

常用这些功能的话，建议把本程序改成 `Ctrl+Alt+1`、`Ctrl+Alt+2`、`Ctrl+Alt+3`。

反过来，如果某个键已被别的程序占用，保存设置或启动时托盘会提示“快捷键不可用”，并写明是哪一个，换一个即可。
其余快捷键照常工作。

### 4.4 投屏窗口里的快捷键

下面这些是 scrcpy 自带的，只在投屏窗口里有效，不能在设置里改。和 `Alt+1/2/3` 不冲突。

| 快捷键 | 功能 |
| --- | --- |
| 左 `Alt+F` 或 `F11` | 全屏 / 退出全屏 |
| 左 `Alt+H`、左 `Alt+B`、左 `Alt+S` | 主页、返回、最近任务 |
| 鼠标右键、鼠标中键 | 返回、主页 |
| 左 `Alt+↑`、左 `Alt+↓` | 音量加、减 |
| 左 `Alt+O`、左 `Alt+Shift+O` | 关掉平板屏幕但继续投屏、重新点亮 |
| 左 `Alt+P` | 电源键 |
| 左 `Alt+R` | 旋转平板屏幕 |
| 左 `Alt+N` | 展开通知栏 |
| 左 `Alt+C`、左 `Alt+X`、左 `Alt+V` | 复制、剪切、粘贴电脑剪贴板 |
| 左 `Alt+G` | 窗口恢复 1:1 |
| 左 `Alt+K` | 打开平板的实体键盘设置 |

把电脑文件拖进投屏窗口可以传到平板；拖 APK 会直接安装。

## 5. 画质预设

| | 低延迟（默认） | 高画质 |
| --- | --- | --- |
| 分辨率上限 | 1920 | 不限 |
| 码率 | 8 Mbps | 16 Mbps |
| 编码 | H.264 | H.265 |
| 声音 | 留在平板 | 传到电脑 |
| 窗口置顶 | 是 | 否 |

- 临时切换：`Ctrl+Alt+P`，或右键 → 切换预设。会短暂断开重连，重启程序后回到默认预设。
- 改默认预设、改参数：右键 → 设置…。改乱了点“恢复这个预设的默认值”。
- 画面卡：把“分辨率上限”降到 1280。
- 平板不支持 H.265 时会自动改用 H.264。

## 6. 无线投屏

1. 先插线投屏，确认电脑和平板在同一个 Wi‑Fi。
2. 右键托盘图标 → 切换到无线。
3. 画面恢复后就可以拔线。

码率会自动限制在 4 Mbps 以内。平板重启或换 Wi‑Fi 后无线会失效，重新插线再切一次。
无线投屏时 `Alt+1/2/3` 用法不变。

## 7. 用电脑键盘打中文

投屏时电脑键盘相当于插在平板上的实体键盘。

1. 第一次用：点一下投屏窗口，按左 `Alt+K` 打开平板的实体键盘设置，选好键盘布局。
2. 之后用平板自己的输入法打字，按它的快捷键切换中英文（多为 `Ctrl+空格` 或 `Shift`）。

## 8. 配置和日志

都在 `%APPDATA%\TouPing`（在资源管理器地址栏粘贴即可打开）：

- `config.json`：所有设置。快捷键对应 `hotkey_show`、`hotkey_minimize`、`hotkey_close`、`hotkey_toggle`、
  `hotkey_preset`，留空 `""` 表示不用。要手动改，**先退出程序**，否则会被覆盖。
- `touping.log`：日志，报问题时带上它。

恢复全部默认设置：退出程序，删掉 `config.json`，再启动。

卸载：先在设置里取消“开机自动启动”，退出程序，再删掉程序文件夹和 `%APPDATA%\TouPing`。

## 9. 常见问题

| 现象 | 处理 |
| --- | --- |
| `Alt+1/2/3` 没反应 | 确认托盘里有图标；关掉设置窗口；确认按的不是小键盘；看设置里有没有被改掉；确认运行的是新版本 |
| 提示“快捷键不可用” | 被其他程序占用，到设置里换一个 |
| 按 `Alt+1` 提示“没有检测到设备” | 平板没连上，按 1.5 检查 |
| `Alt+1` 在别的软件里失效了 | 见 4.3，把本程序的快捷键改成 `Ctrl+Alt+1` 等 |
| 记不住改成了什么 | 右键 → 使用说明，里面显示的是当前快捷键 |
| 插上没反应，图标一直是灰色 | 换能传数据的线；平板 USB 用途选“传输文件”；装品牌官方 USB 驱动 |
| 图标是黄色 | 解锁平板，点允许 USB 调试 |
| 图标是空心绿，不自动投屏 | 之前手动关过，按 `Alt+1` 或重新插线 |
| 有画面，但键鼠不起作用 | 小米、红米打开“USB 调试（安全设置）” |
| 反复断开 | 关掉手机助手、刷机工具、模拟器，再重新插线 |
| 提示“缺少投屏组件” | 打包版重新解压完整文件夹；源码版运行 `scripts\fetch_scrcpy.ps1` |
| 没有声音 | 低延迟预设默认不传声音，换高画质，或在设置里取消“关闭音频” |
| 不能开 USB 调试 | 右键 → 免 USB 调试投屏，限制见[免USB调试可行性](免USB调试可行性.md)。`Alt+1/2/3` 管不到这种投屏 |
